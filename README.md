## The line

> My love language is acts of service, because I literally cannot do anything else. I will remember your coffee order forever. I have no choice.

142 Unicode code points — inside the 1–180 limit.

## How it works

`main.ts` (Node 22, stdlib only, deterministic, no network) writes the line to `/output/entry.txt`. It also guards the gate itself: the line must be 1 to 180 Unicode code points, a single line, and not only whitespace, or the program fails loudly instead of shipping an invalid entry.
